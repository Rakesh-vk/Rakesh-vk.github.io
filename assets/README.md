# Rakesh Kuratti — Portfolio

Static portfolio website for GitHub Pages.

## Deploy

1. Create/use a repository named `Rakesh-vk.github.io` if you want the site at:
   `https://Rakesh-vk.github.io`
2. Copy the contents of this folder into the repository root.
3. Commit and push to the default branch.
4. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
5. Select the default branch and `/ (root)`.

No build step is required.

## Files

- `index.html` — page structure/content
- `styles.css` — responsive styling
- `script.js` — navigation, scroll progress and reveal animations
- `assets/profile.jpg` — supplied profile photograph
- `assets/resume.pdf` — supplied resume
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing

## Notes

The site intentionally avoids cookie/notification popups and third-party analytics.
All content is static and suitable for GitHub Pages.
